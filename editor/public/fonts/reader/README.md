# Offline reader fonts

Unmodified font files from the Google Fonts repository, downloaded 2026-10-15. Bundled for offline EPUB use; no runtime request is sent to a font service. Each family's OFL license is included beside its files.

- Literata: https://www.type-together.com/literata-font and https://github.com/google/fonts/tree/main/ofl/literata
- Atkinson Hyperlegible Next: https://www.brailleinstitute.org/freefont/ and https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext
- Kalam: https://github.com/itfoundry/kalam and https://github.com/google/fonts/tree/main/ofl/kalam

Georgia, system sans and Typewriter (Courier New/Courier fallback) use local system fonts. Font preferences are personal; these choices do not claim universal reading or accessibility benefits. Unsupported glyphs use platform fallback fonts.
