# Bundled fonts

Unmodified font files from the official Google Fonts repository, downloaded 2026-10-12. Each family includes its SIL Open Font License alongside the font.

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- Lora: https://github.com/google/fonts/tree/main/ofl/lora
- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Orbitron: https://github.com/google/fonts/tree/main/ofl/orbitron
- Monoton: https://github.com/google/fonts/tree/main/ofl/monoton

The Diane prefix is a CSS family alias, not a modification to the font files. Fonts load locally on demand; no runtime font CDN is used.

- Tilt Neon: https://github.com/google/fonts/tree/main/ofl/tiltneon
