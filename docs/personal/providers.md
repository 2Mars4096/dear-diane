## Common adapter gate

For each candidate: connect/refresh/revoke, least scopes, pagination/cursors, account isolation, duplicate events, rate limits, timezone/DST, conflicts, unknown outcomes, and deletion/retention. Pin any reviewed MCP tool schema and classify side effects; documentation or catalog presence alone is insufficient. No provider registration, login, account mutation or external message was performed during this research.
