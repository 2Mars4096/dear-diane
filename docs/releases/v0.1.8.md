# Dear Diane 0.1.8

- Improve typing responsiveness, multiline composer sizing, and rendering during team activity.
- Open long saved conversations without fetching every historical run; show the latest 40 messages with a Load earlier messages button.
- Add collapsible Lead summaries in chat, readable worker task/results, and links to full worker conversations.
- Support native Claude permission modes, independent command sandbox settings, and actionable questions beside the composer.
- Notify native leads when workers finish so they can review results and consider remaining requested work. Keep the same run alive for worker handoffs instead of closing workers with an early lead reply.
- Reduce worker polling, event-log scans, hidden rendering, and repeated full-state writes.
- Improve backend interpreter selection, proxy disconnect handling, and small macOS app icons.
- Use DIANE_* names in configuration examples; legacy DAN_* names remain compatible, with DIANE_* taking precedence.

Apple Silicon desktop update for existing configured Diane installations. Use the matching Python backend source from tag `v0.1.8` for worker handoffs, permission controls and configuration aliases; the desktop updater does not bundle or upgrade Python. Chats, credentials and settings are preserved.

Automated completion, cancellation and same-session handoff tests pass. Live-provider acceptance of completion-driven reassignment remains pending; delivery does not guarantee that a model assigns further work. Automatic stalled-command termination is not included.
