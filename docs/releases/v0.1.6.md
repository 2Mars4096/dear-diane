# Dear Diane 0.1.6

- Add conversational Plan mode with `/plan`, saved scope and next steps, and an explicit start action.
- Answer up to three planning questions inline, including multiple selections, Other answers and comments. Clear choice controls and bordered rows keep decisions readable.
- Improve EPUB navigation, page counts, file drops and references; retain reading state across layout changes.
- Add appearance choices and fonts, improve project/chat routing, and show readable references in queued messages.
- Improve provider/account usage reporting, composer steering and queue shortcuts, startup diagnostics and local update cleanup.

Apple Silicon desktop update for existing configured Diane installations. Plan mode requires the matching Python backend source from this release; the desktop updater does not bundle or upgrade Python. Provider credentials and existing chats/settings are preserved.
