# Project Overview

DAN is one durable-agent product organized into four layers: Universal Cell, Universal Organism, Super DAN, and the Work/Notes GUI.

The system separates:

- protected user intent and acceptance criteria (Task Blueprint);
- adaptable execution choices (Execution Attempt);
- bounded worker specialization (WorkerBrief);
- deterministic scheduling/admission policy;
- replayable events, evidence, validation, and operator commands.

The active roadmap is [plans 1–5](todo.md). Historical graph-builder, editor-mode, messaging, concierge, RAG, publishing, and product-specific organism work is intentionally absent from the active tree and remains accessible in Git.
