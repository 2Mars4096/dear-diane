# 12-6: Chat Quality Harness

**Parent:** [12-cursor-parity-chat](12-cursor-parity-chat.md)
**Status:** in-progress
**Goal:** Build a testing and evaluation framework that catches regressions, measures chat quality across providers, and provides confidence for shipping changes throughout Phase 7.2.

## Current State

- 24 integration tests in `test_chat_integration.py` covering modes, streaming, mentions, stop, export/search
- 37 mutation regression tests in `test_mutation_regression.py` (10 golden prompts × 3 evaluations + error handling + JSON fallback)
- 19 provider compatibility tests in `test_provider_compat.py` (interface, routing, extraction fallback)
- 13 metrics tests in `test_mutation_metrics.py` (unit + endpoint integration)
- Metrics collector enhanced with `retry_count` and `stale_plan_count` tracking
- Provider compatibility documented: OpenAI (structured tool_calls), Anthropic/Google (JSON fallback)

## Decisions

- Used 10 golden prompts (not 15-20) for the regression suite — sufficient to cover all operation types and patterns. Expanding to 20+ is straightforward.
- Provider compat tests are offline (mock-based), not live API tests. Live testing deferred to CI schedule.
- Metrics enhancements are backward-compatible: `summary()` dict now includes `total_mutations`, `failed_applies`, `retry_count`, `stale_plan_count` in addition to existing fields.
- Tasks 5 (latency benchmarks) and 6 (E2E browser tests) deferred — require Playwright setup and CI infrastructure.

## Notes

- This sub-plan should start alongside 12-1 so that reliability fixes can be validated immediately.
- The NL→mutation regression suite (task 2) is the highest-value deliverable — it prevents quality regressions during all subsequent Phase 7.2 work.
- Provider compatibility (task 3) directly addresses the "Anthropic/Google don't populate tool_calls" finding from the audit. The test matrix will document what works and what falls back to JSON extraction.
- Mutation metrics (task 4) absorbs three backlog items from plan 10-8 (tasks 11-2, 11-3, 11-5).
