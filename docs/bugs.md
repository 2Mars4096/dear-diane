# Known Issues & Failed Approaches

## Open Bugs

- **Vibe research LLM calls may fail with provider quota/auth errors**: External dependency issue (`vectorengine.ai` returning 401/403 such as `Token not provided` or `insufficient_quota`). Workflow currently continues with fallback-safe outputs, but strategy generation/backtests degrade when LLM nodes fail.

## Resolved Bugs

- **`_rag_index_documents` sent `list[str]` to `Indexer.create_index` (expects `list[dict]` with `"text"` key):** Indexer silently failed to build a collection. Fixed by wrapping document content as `{"text": ..., "metadata": ...}`.
- **`_rag_index_documents` bypassed workspace sandboxing:** Absolute `pdf_dir` was resolved as-is via `Path(workspace) / pdf_dir`, escaping `DAN_WORKSPACE_ROOT`. Fixed by rejecting absolute paths and verifying the resolved path stays under the workspace root.
- **`TOOL_PORT_MANIFESTS` mismatched `compile_latex`/`save_paper`/`package_submission` signatures:** Manifests declared generic `input`/`tex_content` ports while tools required `title`, `content`, `tex_path`, `bib_path` as separate arguments. Caused `TypeError` at runtime. Fixed by aligning manifests with actual function signatures and adding structured output ports.
- **`data_ingest` pattern wired `list_directory` dict output into `rag_index_documents` string param:** `list_directory.result` is `{"entries": [...], "count": N}` but was connected to `pdf_dir` (string). Caused `TypeError`. Fixed by removing the intermediate `list_directory` node — `rag_index_documents` does its own file discovery internally.
- **`informs_paper_writing` template implicitly auto-created `context` port on Outline Planner:** `add_edge` targeting a nonexistent port generated a diagnostic warning and contradicted strict-mode hardening. Fixed by declaring explicit `input_ports` config on the Outline Planner node.
- **Flow parser crashed on non-integer `parallel`/`max` kwargs:** `each()`, `loop()`, and `parallel()` called `int()` directly on kwargs without catching `ValueError`. Fixed by wrapping in try/except and raising `FlowParseError` with the offending value.
- **Editor ConfigPanel: clearing input mapping text deleted the row:** `updateInputMapping` deleted the mapping when inner port was empty string, causing the input row to vanish mid-edit. Fixed by always storing the value; deletion is via the explicit `×` button.
- **Loader silently accepted unknown merge strategy in parallel():** An unrecognized `merge:` value (e.g. `merge: unknown`) silently defaulted to APPEND. Fixed by emitting a diagnostic error listing valid strategies.
- **Decompiler `_invert_until_condition` could truncate trailing expressions:** `not (A) or B` was incorrectly stripped to `A`. Fixed by checking for trailing content after the closing paren; if present, the original string is returned unchanged.
- **Markdown loop decompile/compile could invert semantics and drop loop state:** Fixed in Plan 7-8 — decompiler now inverts `gate.condition` back to `until` (strips one `not (...)` layer) and emits `state:`/`defaults:` when present. Round-trip preserves semantics.
- **ContextEdge read permission validation checked source node, while runtime reads on target node:** Fixed in Plan 7-8 — `_check_context_edge_permissions` now validates `target_node_id`'s `read_set` for READ mode (consumer); WRITE/APPEND still validate source.
- **Gate while-mode could be miswired by default chain/f-string wiring:** Fixed in Plan 7-8 — builder `default_output_port` is now mode-aware: `gate_mode="while"` → `"continue"`, `gate_mode="if_else"` → `"true"`.
- **Flow parse failures were warnings (not fatal) in markdown compiler:** Fixed in Plan 7-8 — `compile_workflow(path, strict=True)` treats parse_warnings as errors; ambiguous bare-edge also fails in strict mode.
- **Mutator auto-created missing target ports silently:** Fixed in Plan 7-8 — mutator now adds diagnostic on auto-create; optional `strict=True` on add_edge fails instead of auto-creating.
- **Generated custom strategy code was not persisted for reproducibility:** Workflow could execute custom `build_factor` code but did not save the script artifact, making exact reruns hard. Fixed by saving scripts before execution to `examples/vibe_research_md/output/scripts/{strategy}.py` in `_run_strategy_script`, and propagating `script_saved_path`/`script_save_error` through `bug_fixer` and `save_tracking` outputs.
- **Sub-$1 stocks were included at portfolio formation in vibe backtests:** Formation universes were not consistently filtered by price, so penny stocks could enter quintile sorting. Fixed by enforcing `|price| >= 1` in `quant_lib` backtests: built-in momentum/reversal now carry formation price and filter directly; custom-factor backtests auto-attach CRSP price by `(date, permno)` when missing and apply the same threshold.
- **`skip` gate wiring suppressed plots on non-skip runs (factors produced, no figures):** `department.md` routed `dept_gate.if(skip).true` into `bug_fixer`, and scheduler skip semantics treat missing gate branch data as inactive. On normal `skip=false` runs, this could skip `bug_fixer` before backtest outputs arrived, so factors were saved but plotting never executed. Fixed by isolating halt routing to `dept_halt.md` and making `bug_fixer` return `{}` when no backtest payload is present.
- **Generated custom scripts crashed with `incompatible tolerance <DateOffset: months=...>` in `merge_asof`:** Some LLM scripts pass `pd.DateOffset` as `merge_asof(tolerance=...)`, which pandas rejects for datetime64 join keys. Fixed in `_run_strategy_script` safe merge wrapper by normalizing/removing incompatible tolerance and retrying.
- **Custom build scripts could print internal errors and return empty factors, causing “factors but no figures” confusion:** Generated `build_factor` code sometimes catches internal exceptions and returns an empty-but-schema-valid DataFrame after printing diagnostics. Runtime used to persist/backtest these empties, producing no plot series. Fixed by capturing `build_factor` stdout/stderr in `_run_strategy_script` and hard-failing empty factor outputs before save/backtest.
- **Department composite output shape mismatched merge expectations:** `department.md` exits through `save_tracking`, but merge logic consumed department outputs as backtest dicts. This caused empty/partial downstream results visibility even when factor/backtest work ran. Fixed by making `save_tracking` return passthrough backtest fields (`strategy_name`, `quintiles`, spread, series, plot metadata) in addition to persistence paths.
- **`max_factors` appeared ignored (many factors generated when set to 2):** Stop logic only counted successful `results`, so failed attempts could continue until safety-cap iterations and still emit many factor files. Fixed by capping on attempted strategies too (`len(strategies_tried) >= max_factors`) in `governor.md`.
- **Factors existed but no immediate machine-readable results file:** Department flow produced factors/plots but lacked per-factor result artifacts for quick inspection. Fixed by writing `output/results/{strategy}.json` and `output/latest_result_{dept}.json` in `save_tracking.md` after each backtest.
- **Backtest/plot visibility lagged until end-of-run:** Top-level plotting and CSV export happened after the while-loop `done`, so users could not see progress as factors completed. Fixed by plotting inside `bug_fixer` per factor and updating `tracking_{dept}.json` immediately after each backtest via `save_tracking(backtest_result=...)`.
- **Departments backtested in parallel when one-by-one debugging was needed:** Iteration executed MOM/REV/FUND in parallel fan-out. Fixed by serializing department assignment flow with dependency gates (`MOM -> REV -> FUND`) so each department backtest completes before the next starts.
- **FUND/custom strategies produced no persisted factor files:** Builtin backtests saved factor parquet files via CLI `--save-factor-dir`, but custom `run_strategy_script` path only returned backtest metrics and did not persist factors. Fixed by saving `factor_df` to `examples/vibe_research_md/output/factors/<strategy_name>.parquet` and returning `factor_saved_path` (plus non-fatal `factor_save_error`).
- **Generated custom scripts failed on `name 'ValueError' is not defined`:** Sandbox builtins only exposed `NameError` and `Exception`, so standard `except ValueError` patterns in generated code crashed. Fixed by adding common exception classes (`ValueError`, `TypeError`, `KeyError`, `IndexError`, `AttributeError`) to `_ALLOWED_BUILTINS`.
- **Raw `pd.merge_asof` in generated code still failed with `left keys must be sorted`:** Even with prompt guidance, generated code could call unsorted `pd.merge_asof`. Fixed in `_run_strategy_script` by temporarily monkey-patching `pd.merge_asof` to a safe sorting wrapper during code execution/build_factor invocation.
- **Legacy Compustat names in stale tracking params broke FUND runs (`ceq` vs `ceqq`, `at` vs `atq`):** Fixed by adding backward-compat alias columns in `load_compustat()` and normalizing common param aliases before `build_factor` execution.
- **merge→governor dropped `new_strategies` port:** The bare edge `merge → governor` hit the compiler's ambiguity path (two matching ports: `new_results`, `new_strategies`) and only wired the first alphabetically. `strategies_tried` never accumulated, causing the orchestrator to repeat strategies. Fixed with explicit `merge.new_results → governor.new_results` + `merge.new_strategies → governor.new_strategies`.
- **dept_gate.theme never reached strategy_manager:** Orchestrator generated per-iteration themes but `department.md` never wired `dept_gate.theme` to `strategy_manager.theme`. Strategy manager operated without theme context. Fixed by adding the edge and a `{theme}` reference in the prompt.
- **dept_gate.skip unused — halted departments ran full pipeline:** `dept_gate` set `skip=true` when `action=="halt"`, but no gate consumed it. Halted departments still made LLM calls and ran backtests. Fixed by adding `dept_gate | if("skip", then: bug_fixer, else: load_tracking)` to short-circuit halted departments.
- **Builtin backtest always ran momentum, ignoring reversal:** `run_backtest()` hardcoded `build_momentum()` and `strategy_name="momentum_..."` regardless of `factor_name`. REV department computed 1-month past return but never negated it. Fixed: negate signal for reversal, label correctly, pass `factor_type` through item.
- **Merge silently dropped all department results (REV, FUND, and even MOM):** `merge.md` looked for `c.get("backtest_result")` and `c.get("strategy_id")`, but department composites output the backtest dict directly (keys: `quintiles`, `strategy_name`, `spread_q5_q1_bps`, etc.) — no nesting. So `new_results` and `new_strategies` were always `[]`, governor accumulated nothing, and the loop ran until max iterations with an empty results list. Fixed merge to treat each department input as the backtest result itself and use `strategy_name`.
- **LLM-generated code used wrong Compustat column names (`at` instead of `atq`, `ceq` instead of `ceqq`, etc.)**: Fixed — strategy coder prompt now includes full quarterly column reference from user-provided DATA-DICTIONARY.md. `load_compustat()` and `safe_merge_asof()` injected into sandbox namespace. Strategy manager prompt updated with concrete column examples per department theme.
- **Custom strategy scripts crashed with `KeyError: ['ret']`**: Fixed — `load_crsp()` now normalizes a canonical `ret` alias (from `return_month` or `return_ex_div_month`) and keeps `mktcap`/`market_cap_month` aliases aligned. This matches strategy-coder contract and prevents `build_factor(...).dropna(subset=["ret"])` failures.
- **Vibe run crashed when saving checkpoints (`ValueError: Circular reference detected`)**: Fixed — removed self-referential strategy output (`out["result"] = out`) from `_run_strategy_script`, so checkpoint JSON serialization no longer encounters recursive dictionaries.
- **Generated strategy code failed with `NameError: name 'next' is not defined`**: Fixed — added `iter` and `next` to the sandbox/code executor allowed builtins used by `execute_python()`.
- **`Engine.run(inputs=...)` lost on InputNode variables**: Fixed — scheduler now injects virtual run inputs into `InputNode.variables` (not just `input_ports`), so workflow inputs like `start_year/end_year/max_factors` propagate correctly.
- **While loop body ran before initial gate continue signal**: Fixed — skip logic for `gate.continue/loop` now only bypasses gate-source checks when virtual loop-feedback inputs are present, preventing premature first-pass body execution.
- **Drop position wrong when zoomed/panned**: Fixed — replaced manual `clientX - bounds.left` with `screenToFlowPosition()` from `useReactFlow()` in `GraphCanvas.tsx`.
- **Node ID collisions after page refresh**: Fixed — replaced module-level `_counter` with `Date.now()` + random suffix in `graphAdapter.ts`.
- **Delete key doesn't fire reliably**: Fixed — removed wrapper `onKeyDown` handler, added `deleteKeyCode={["Delete", "Backspace"]}` prop to `<ReactFlow>` in `GraphCanvas.tsx`.
- **`onConnect` creates mismatched edge IDs**: Fixed — extracted `Date.now()` to a single `edgeId` const in `useGraphStore.ts`.
- **`hasBodyGraph` in App.tsx uses useCallback, should be useMemo**: Fixed — changed to `useMemo` returning a boolean, updated call site from `hasBodyGraph()` to `hasBodyGraph`.
- **`Object.groupBy` compatibility in `NodePalette`**: Fixed — replaced `Object.groupBy` with a typed `reduce` grouping implementation, removing ES2024 dependency.
- **Read-only drill-in bypassable**: Fixed — `NodePalette` and `ConfigPanel` now disable all add/edit/drag actions when `layerStack.length > 0`.
- **Template port contract mismatch**: Fixed — LLM template output port renamed to `text` (matching executor), ReAct condition to `True`, Plan-Execute given proper port mappings.
- **`startRun()` proceeds after failed save**: Fixed — `saveGraph()` returns boolean, `startRun` aborts if `false`.
- **Edge type edit doesn't update styling**: Fixed — `updateEdgeData` syncs top-level `animated`, `label`, `style.stroke` when `edge_type` changes.
- **Subgraph events lack hierarchy tags**: Fixed — `layer_path` threaded through `ExecutionContext` and emitted with every event.
- **LogPanel shows node IDs instead of names**: Fixed — `nodeNameMap` reads `data.name` (not `data.label`).
- **Paper workflow LaTeX compile fails on missing INFORMS assets/citation keys**: Fixed — `compile_latex` now auto-fetches `informs3.cls`, normalizes TeX for `plainnat` compatibility (`hyperref`, `\newblock`), and auto-fills missing BibTeX keys with placeholder entries.

## Known Limitations

- **reactFlowEdgeToDan can drop edge metadata (11-3):** When `rfEdge.data?.danEdge` is absent, the adapter creates a default DataEdge with `edge_type: "data"`, losing `edge_type` (control/context), `spread`, `context_key`, `mode`, `condition`. Ensure editor-created edges always preserve `danEdge` on `data`.
- **DEFAULT_OUTPUT_PORTS inconsistency (11-1):** Builder vs mutator disagree on composite (`result` vs `output`) and while_loop (`result` vs `output`). May cause port mismatches when mutator adds nodes. Future: extract to shared `dan.models.ports` or `dan.constants`.
- **TS NodeBase lacks read_set/write_set (11-1):** Python `NodeBase` has `read_set`/`write_set` for context declarations; `editor/src/types/graph.ts` omits them. Round-trip and ContextEdge validation may lose fidelity. Add to TS interfaces for parity.
- **Loader feature gaps (11-3):** Markdown loader emits only DataEdge; no ControlEdge or ContextEdge. Loader cannot define RAG, Validator, Reduce nodes. Round-trip via markdown loses control/context edges, artifact_refs, loop_groups. Use Python/JSON canonical source for full fidelity.
- **No graph validation in editor**: The frontend saves graphs without running the Python validation rules (`validate_graph`). Invalid graphs (missing entry points, broken edges) can be saved and will fail at run time. Validation feedback in the editor is a future enhancement.
- **Single-user only**: The run manager holds state in memory. Multiple browser tabs can connect to the same run via WebSocket, but there's no multi-user session isolation.
- ~~**No error feedback — silent API failures**~~: Resolved in Phase 3.5 — toast notification system added; all store actions wrapped in try/catch with error toasts.
- ~~**No loading states**~~: Resolved in Phase 3.5 — `loadingGraph`/`savingGraph` flags with spinners in `EditorToolbar`.
- ~~**No connection validation**~~: Resolved in Phase 3.5 — `isValidConnection` callback added in `GraphCanvas` (rejects self-connections, duplicates).
- **ConfigPanel is a generic field dump**: Iterates all non-skipped fields without logical grouping. JSON fields have a raw textarea with silent `JSON.parse` catch — no validation feedback. No way to add/remove/rename ports. (Partially improved: edge config is now editable with type-specific fields.)
- ~~**Fixed-height bottom panel**~~: Resolved in Phase 3.5 — resizable panels via `allotment`.
- ~~**Two header bars waste vertical space**~~: Resolved in Phase 3.5 — merged into single `EditorToolbar`.
- ~~**No keyboard shortcuts**~~: Resolved in Phase 3.5 — Cmd+S save shortcut added.
- **No undo/redo**: React Flow supports undo/redo via state snapshots, but it's not wired up yet.
- **App title/favicon are Vite defaults**: HTML title is "editor", favicon is `vite.svg`. Basic branding gap.
- **Node.js version warning**: Vite 7.x and `@vitejs/plugin-react` require Node.js 20.19+ or 22.12+. Current dev environment runs 20.17 — builds succeed with warnings but may break on future Vite updates. Fix: upgrade Node.js.
